## 업데이트 방법

1. `index.html`을 수정합니다. (백업본도 같이 맞추려면 `style-guide.html`에 복사해 두세요)
2. 변경사항을 커밋하고 푸시합니다.

   ```bash
   git add -A
   git commit -m "스타일 가이드 내용 수정"
   git push
   ```

3. 푸시 후 **1~2분** 정도면 GitHub Pages에 반영됩니다.
   바로 안 보이면 브라우저 강력 새로고침(`Ctrl+Shift+R`)을 해보세요.

수정할 때 이 README의 **마지막 수정일**도 같이 고쳐주면 문서가 언제 기준인지 헷갈리지 않습니다.
